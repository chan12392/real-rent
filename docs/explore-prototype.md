# 대화·지도·캐릭터 웹 시제품

작업 브랜치: work/yunsoo. 합성 데이터 시제품이며 공개 배포는 아직 수행하지 않았다.

## 합의한 경험

크림색·초록색 강조, 기본 글자 #333333. 왼쪽 대화/고정 캐릭터, 넓은 지도,
집 선택 후 상세 패널. 실제 위치·거리와 다른 시연 지도이며 외부 지도 API를 호출하지 않는다.
추천 판정 집 모두에 작은 얼굴을 표시하고 나머지는 동일 집 마커를 사용한다.
모든 집은 선택 가능하며 선택한 집을 유지한 채 조건 수정 시 판정·표정·이유를 갱신한다.
캐릭터는 부위별 SVG와 CSS로 호흡·눈 깜빡임·귀 움직임·기쁨·고민·걱정·검색 동작을 표현한다.
움직임 줄이기 OS 설정을 따른다. 이미지 시트 자체가 아닌 웹 애니메이션용 시안이다.

대화는 친근한 존댓말, 규칙 기반 추출·모호한 표현 재질문. 필수/선호는 카드와
‘꼭/가능하면’ 표현으로 변경한다. 첫 기본값을 확인하는 버튼을 제공한다.
월 지출은 월세+관리비+통근비. 출근 기본 20일. 환승 기본 제한 없음.
API 규약·미확인 우선순위·지원 표현은 docs/api.md를 따른다.
화면을 사용한 뒤 상세 패널 정보량을 사용자와 재검토한다.

## 실행

Node/Python 버전은 루트 README 기준. 루트에서 `npm run setup`, `npm run dev`.
신규 기본 화면은 `/`, 기존 비교 화면은 `/?view=legacy`다.
이미 5173/8000이 사용 중이라면 기존 프로세스를 종료하지 말고 별도 터미널에서:

```sh
# 루트 · 서버
uv run --directory backend uvicorn app.main:app --host 127.0.0.1 --port 8005
# 루트 · 별도 터미널의 화면
API_PROXY_TARGET=http://127.0.0.1:8005 npm --prefix frontend run dev -- --port 5175
```

화면 http://127.0.0.1:5175. 종료는 각 실행 터미널 Ctrl+C.
실제 키·LLM·외부 지도·웹폰트 없이 동작하지만 의존성 설치에는 네트워크가 필요하다.

## 검증 시나리오

1. 첫 진입에서 12개 기본 마커, 추천 없음.
2. ‘보증금 천만 원, 월 80만 원, 강남역까지 40분’ → 임시 판정·입주일 질문.
3. 추천 집 클릭 → 비용/양방향 통근/판정·메인 토끼 기쁨 반응.
4. ‘월 50만 원은 꼭 지켜줘’ → 같은 선택 집 유지, 필수 위반·걱정 반응.
5. ‘가능하면 원룸’ 또는 ‘환승 없이’ → 선호/환승 조건 반영.
6. 관리비·경로 누락 집 선택 → null/미확인 이유 표시.
7. 새로고침 후 대화·조건·선택 집 복원. 새로 찾기로 초기화.
8. 서버 연결 실패 시 입력 보존·재연결, 이전 결과는 경고 표시.
