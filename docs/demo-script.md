# 5분 발표 시연 시나리오

대화로 조건을 말하면 캐릭터가 반응하고, 확인한 조건으로 합성 매물 12건을 비교하는 흐름이다.
**모든 매물·가격은 합성 시연 데이터이고, 의미 판단은 규칙 기반(LLM 없음)이다.** 이 점을 시연 중에 숨기지 않는다.
보금이는 오리지널 캐릭터(AI 생성 시안)이며 생성 도구 이용약관상 권리 귀속은 확인 필요다([acceptance.md](acceptance.md) AT10). 외부 공개 전에 권리 확인 결과를 먼저 본다.

## 시작 전 준비 (발표 10분 전, Windows PowerShell)

저장소 루트에서 터미널 두 개. 한 번이라도 `npm ci`·`uv sync --frozen`을 해 두었으면 인터넷 없이도 돈다(외부 CDN·웹폰트 없음).

```powershell
# 터미널 A — 서버
cd backend
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

```powershell
# 터미널 B — 화면
cd frontend
npm run dev
```

- 브라우저에서 <http://127.0.0.1:5173> (기본 캐릭터 = 보금이). 렌티로 보려면 `?skin=renti`.
- 준비 확인: `Invoke-RestMethod http://127.0.0.1:5173/api/health` → `status: ok`.
- 사전 점검(선택): 화면 터미널에서 `node scripts/check-chat.ts` → “모두 통과”.
- 브라우저 확대 100%, 창 폭 1280 이상, 알림 끄기. 보금이 이미지가 없는 PC에서는 자동으로 렌티가 나온다.

## 진행 순서 (총 5분)

| 시간 | 단계 | 화면에서 할 일 | 핵심 한 줄 |
|---|---|---|---|
| 0:00 | 1. 서버 실행 | 터미널 A·B가 떠 있는 것을 짧게 보여 준다 | “서버 하나, 화면 하나로 노트북에서 돌아갑니다. 인터넷이 없어도 됩니다.” |
| 0:30 | 2. 첫 화면 | 보금이가 인사하는 기본 화면, 합성 데이터 배지, 입력창 아래 **예시 칩**(‘월세 60 이하로’ 등 4개), 기본 조건으로 이미 계산된 결과. 조건 패널의 **‘생활 조건 (참고 계산용)’ 접이식**은 닫혀 있다 | “처음부터 기본 조건으로 비교가 되어 있고, 모든 매물은 합성 시연 데이터입니다.” |
| 1:00 | 3. 대화로 조건 입력 | 입력창에 “월세 90 이하로, 60분 안쪽” 입력(예시 칩 ‘월세 60 이하로’·‘40분 안쪽’을 눌러도 됨). 입력하는 동안 보금이가 듣는 표정 | “타자 칠 때의 반응은 서버와 무관한 화면 쪽 반응이고, 보내면 의미를 읽어 표정을 바꿉니다.” |
| 1:45 | 4. 확인 카드 | “이렇게 바꿀까요?” 카드의 ‘확인 필요’ 칩·설명을 읽고 **모두 반영** | “단위 없는 ‘90’은 만 원으로 읽었다고 알려 주고, 제가 누르기 전에는 조건이 바뀌지 않습니다.” |
| 2:15 | 5. 비교 | ‘이 조건으로 비교하기’ → 보금이가 결과를 말함. 아래 추천 TOP 3·통과/탈락 건수 | “표정은 계산에 쓰이지 않습니다. 같은 조건이면 순위와 금액이 똑같습니다.” |
| 2:45 | 6. 보금이 반응·설명 + 참고 월 거주비 카드 | 말풍선의 1위·2위·3위 월 지출·왕복 시간, 마지막 합성 고지. 추천 카드의 점선 상자 **‘진짜 월 거주비(참고) 참고·시안’**(예: 1위 672,555원, 범위 663,017~682,694원)을 가리킨다 | “설명 속 숫자는 서버 응답의 값 그대로이고, 모르는 값은 ‘미확인’이라고 씁니다.” |
| 3:15 | 7. 관리비 직접 입력 재계산(+ 상세) | 관리비가 확인되지 않은 매물(판단 불가)의 ‘관리비를 알고 있다면 입력해 주세요’ 칸에 60000 입력 → ‘이 관리비로 다시 계산’ → ‘직접 입력’ 태그·순위 확인. 시간이 남으면 통과 매물 하나를 눌러 상세의 ‘월 거주비 항목별 내역’과 접힌 ‘⚠ 검증 필요 값 16개’(펼치면 한글 항목명)를 보여 준다 | “모르는 관리비는 추측하지 않고 판단 불가로 두고, 직접 넣으면 그 값으로 다시 계산합니다.” |
| 4:00 | 8. 질문 패널 | ‘근거 질문’에서 예시 질문을 눌러 근거 문장 확인 | “문서에서 찾은 근거와 함께 답하고, 모르면 모른다고 답합니다. 모델은 쓰지 않았습니다.” |
| 4:30 | 9. 한계·합성 데이터 고지 | 화면 아래 가정 목록을 가리킨다 | “데이터는 합성이고 계산 규칙은 팀 승인 전 초안입니다. 실거래·교통 API, 모델 연결은 다음 단계입니다.” |

※ 3단계 입력 예시는 합성 데이터 기준으로 통과 5건이 나오도록 점검한 문장이다(2026-10-22 실행 기록, [acceptance.md](acceptance.md) AT06·AT07).
7단계 관리비 입력칸은 ‘판단 불가’ 매물을 눌러 연 상세 화면에 있다. 현재 화면에서 한 번 리허설해 위치를 확인한다.
‘진짜 월 거주비(참고·시안)’는 6단계에서 한 줄만 언급한다: “판정·순위에는 쓰지 않는 참고 값이고, 요율·사용량 가정 16개는 검증이 필요합니다.” 생활 조건(인원·난방 등)은 접이식이라 필요할 때만 연다.
보금이 권리 귀속이 확인 필요 상태이므로(AT10 완료 아님) 시연 화면을 녹화·캡처해 외부에 올리기 전에 권리 확인 결과를 본다.

## 지연 수치를 말해야 할 때

로컬 측정이라는 단서와 함께만 말한다. 입력→듣기 반응 중앙값 약 4 ms, 전송→의미 표정 중앙값 약 77 ms(p90 약 90 ms), 비교 응답 약 45 ms(통합 후 재측정, 30회, [latency.md](latency.md)).
“발표장 네트워크나 모델 연결 후의 값이 아닙니다.”

## 실패했을 때

| 상황 | 화면에서 보이는 것 | 대처 |
|---|---|---|
| 서버(터미널 A)가 꺼짐 | 결과 영역에 ‘결과를 불러오지 못했습니다’ + **다시 시도**, 보금이는 사과 표정 | 터미널 A에서 서버를 다시 실행한 뒤 **다시 시도**. 말: “서버 오류와 ‘조건에 맞는 매물 없음’은 다른 메시지로 나옵니다.” |
| 보금이 이미지가 안 뜸 | 렌티(집 모양) 캐릭터로 대체 | 그대로 진행. 말: “이미지 에셋이 없으면 자체 제작 캐릭터로 바뀝니다.” 이미지가 없으면 렌티가 대신 나온다 |
| 표정 서버만 늦음(1.5초 초과) | 표정이 기본으로 돌아가고 조건 확인 카드는 정상 | 그대로 진행. 말: “표정 판단이 실패해도 조건·비교는 계속됩니다.” |
| 입력한 말을 이해 못 함 | “정확히 이해하지 못했어요 …” 류 안내 + 입력 원문 보존(보금이는 반말 문구) | 칩(예: ‘월세 60 이하로’)을 눌러 다시 시도 |
| 화면이 멈춤·이상함 | — | 브라우저 새로고침(F5). 상태는 초기화되고 기본 조건 비교가 다시 뜬다 |
| 포트 충돌(`5173`/`8000`) | 서버 시작 오류 | 다른 포트를 쓰려면 화면: `$env:API_PROXY_TARGET="http://127.0.0.1:8024"; npx vite --port 5194 --strictPort`, 서버: `--port 8024`. 내 PC에서 직접 띄운 프로세스만 종료한다 |

## 종료

각 터미널에서 `Ctrl+C`. 다른 프로세스를 이름으로 일괄 종료하지 않는다.
