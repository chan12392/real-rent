# 연결 규약

## 구현됨: GET /api/health

인증·DB·외부 API가 없어도 실행되는 서버 연결 확인용 API다.

```http
GET /api/health
```

성공 응답 `200`:

```json
{"status": "ok", "service": "real-rent-api"}
```

실행한 서버의 `/docs`와 `/openapi.json`에서 실제 스키마를 확인한다.

## D1 합의 초안: 비교 입력

**아래는 데이터 초안이다. 비교 API와 계산 기능은 아직 구현하지 않았다.**
개발 1·2·3과 분석 담당자가 합의한 뒤 요청·응답 예시, 오류 코드, 테스트를 함께 추가한다.

- 금액: 원 단위 정수. 이름에 `_krw`를 붙인다.
- 기간: 개월 단위 정수. 통근: 분 단위 정수.
- 확인하지 못한 값: `null`. `0`과 구분하고 필수 값이 빠지면 추가 질문한다.
- 매물 식별자: 문자열. 시연 입력 구조는 `data/demo/listings.json`을 참고한다.
- 예상 출력: 초기 필요 현금, 월 지출, 거주 기간 지출, 조건 충족·미달·판단 불가, 근거 목록.
- 보증금 반환을 가정한 비용과 입주 시 현금 필요액을 혼동하지 않도록 각각 이름을 정한다.
- 금액 추정에는 추정 여부·기준 시점·근거를 표시한다.

예정 경로는 팀 합의 후 정한다. 문서에만 있는 기능을 화면에서 호출하지 않는다.
