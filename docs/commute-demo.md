# 통근 중심 비교 데모 · 2026-10-25

이 브랜치는 닫힌 참고용 PR #8의 `c75cbfd`를 기반으로 화면을 개선한 별도 데모다.
원본 main에 통합되지 않았으며 병합용 PR이 아니다. 서버 API·계산·시연 데이터는 변경하지 않았다.

## 바뀐 화면

- 입력과 결과에 목적지 상태를 표시한다. 기존 데이터에는 실제 회사명·주소가 없어 화면에서는 동일 목적지를 ‘시연 회사 A · 목적지 미지정’으로 부른다.
- 대화로 회사·역 이름을 말해도 목적지는 바뀌지 않음을 안내한다. 실제 주소·노선·배차·시간대 조회는 지원하지 않는다.
- 추천 카드 상단에 출근·퇴근 시간, 환승, 도보를 표시한다. 도보는 총시간에 포함된다.
- 비교 기준 매물을 선택해 월 지출 차이, 하루 왕복 시간 차이, 월 통근 시간 차이를 확인한다. 기본 기준은 통과한 최저 월 지출 매물이다. 탈락 매물을 기준으로 선택할 때도 판정 상태를 표시한다.
- 부대경비와 시안 점수는 기존 상세 화면에서 확인한다.
- 폼 변경과 대화 조건 반영 시 이전 결과를 숨기고 재비교를 안내한다. 이전 요청이 늦게 도착해도 결과를 복원하지 않는다. 대화 기록은 이전 조건을 포함한다고 안내한다.

## 실행

Node 24.14 이상 25 미만, Python 3.12, uv가 필요하다. 두 터미널에서 각각 실행한다.

```powershell
cd backend
uv sync --frozen
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

```powershell
cd frontend
npm ci
npm run dev
```

화면은 http://127.0.0.1:5173 이다. 이 주소는 각자 PC에서 실행해야 접속할 수 있다.
기본 보금이 이미지는 포함돼 있고 개인 로컬 스킨은 포함하지 않는다.

## 발표용 확인 순서

1. 월 예산 850,000원, 입주 희망일 2026-11-01, 월 출근일 20일, 편도 최대 40분, 최대 환승 1회, 시간 먼저를 선택한다. 나머지는 기본값이다.
2. 비교하면 문래동 L11, 노량진동 L06, 신길동 L08이 추천된다.
3. 기본 기준인 신림동 L01과 문래동 L11을 비교한다. 월 지출은 632,000원에서 812,000원으로 180,000원 증가하고, 하루 왕복은 78분에서 25분으로 53분 단축된다. 20일 기준 월 1,060분(17시간 40분) 절약이다.
4. 예산이나 환승 조건을 변경하면 이전 결과가 숨겨지는지 확인한다. 대화의 ‘환승 없이’를 확인·반영해도 동일하게 동작한다.

모든 매물·가격·좌표·통근값은 합성 데이터다. 실제 주거지나 실제 통근 경로의 검증 결과로 발표하지 않는다.
