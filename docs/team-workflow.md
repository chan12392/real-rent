# 팀 작업 안내

공통 필수 규칙은 [AGENTS.md](../AGENTS.md) 한 곳에서 관리한다.
담당 경로는 [루트 README](../README.md)의 표를 따른다.

## 한 작업의 순서

1. 이슈에 목적, 담당 경로, 완료 기준을 적고 담당자를 정한다.
2. 최신 `origin/main`에서 본인 작업 브랜치를 만든다.
3. API·데이터 구조를 바꿀 경우 예시부터 공유한다. 상대 기능이 없어도 샘플로 병렬 개발한다.
4. 담당 기능을 구현하고 해당 검사와 실제 연결 경로를 확인한다.
5. 작은 PR을 열고 변경 내용·검증·미확인 사항을 적는다.
6. 다른 팀원의 리뷰가 끝나면 `chan12392`가 병합한다.

이슈·PR의 작성자와 리뷰어는 GitHub에서 실제 팀원 계정으로 지정한다.
아직 팀원 계정이 등록되지 않았으므로 임의의 계정이나 자동 리뷰어는 설정하지 않았다.

## 매일 공유할 내용

- 완료한 일
- 오늘 할 일
- 막힌 점과 필요한 도움

매일 15분 회의에서 연결 상태를 확인한다. 30분 이상 막히면 공유하고 독립 작업을 이어간다.
부재 시 이어받을 수 있도록 실행 방법과 다음 작업을 이슈 또는 PR에 남긴다.
