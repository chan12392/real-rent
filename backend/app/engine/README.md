# 조건 대화·문서 근거·추천 설명 · 개발 3

자연어 조건 추출, 추가 질문·확인 분기, 문서 검색과 추천 이유를 이곳에서 구현한다.
비용 계산·필터·정렬 함수는 분석 담당자의 `app/domain/`에 두고 결과를 가져와 설명한다.
주소·교통 API 호출, 캐시와 제공자 오류 처리는 개발 2의 `app/integrations/`가 맡는다.
요구사항정의서 C15의 경로 응답 정리는 개발 2 담당이며 이 모듈은 정리된 경로를 소비한다.
`explore.py`는 기존 LangGraph로 조건 추출 → 질문/확인 → 비교 → 설명을 연결한다.
`evidence.py`는 매물 ID가 일치하는 로컬 JSON 문서만 검색한다.
모델·API 키 선정은 보류 중이며 벡터 저장소나 모델 의존성을 추가하지 않는다.

- 금액은 원 단위 정수, 기간은 개월, 통근은 분으로 통일한다.
- 모르는 값은 `null`로 유지하고 0원으로 계산하지 않는다.
- 계산식과 추천 기준은 `evaluation/criteria.md`에서 분석 담당자와 합의한다.
- 근거에는 문서 식별자·출처·해당 위치를 남기고, 검색 실패를 정상 답변과 구분한다.
- 공유 근거 문서는 분석 담당자가 `data/references/`에 정리한다. 생성 인덱스는 `data/indexes/`에 둔다.
- 자동 검사는 `backend/tests/engine/`에 추가한다. 외부 모델 없이 확인할 수 있는 사례부터 작성한다.

합성 매물과 규칙 기반 추출로 대화·지도 화면에 연결했다.
전체 조건 확인 전에는 계산·추천·문서 검색을 하지 않으며, 변경 후에는 재확인한다.
실제 모델 생성·임베딩 검색·외부 경로 호출은 미연결이다.
결정 사항과 남은 입력은 [개발 3 안내](../../../docs/development-3.md)를 참고한다.
