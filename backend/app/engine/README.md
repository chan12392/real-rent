# AI · 계산 · RAG · 개발 3

`calc.py`는 순수 함수로 비용 계산·조건 판정·정렬·점수를 처리한다.
`data.py`는 저장소 루트의 합성 CSV를 읽으며 `REAL_RENT_DATA_DIR`로 폴더를 바꿀 수 있다.
`documents.py`는 같은 데이터에서 메모리 근거 문서를 만들고, `retrieval.py`는
문자 2-gram TF-IDF로 검색하며, `qa.py`는 해당 문서의 문장을 인용해 답한다.
LLM·외부 API·파일 기반 검색 인덱스는 사용하지 않는다.

- 금액은 원 단위 정수, 기간은 개월, 통근은 분으로 통일한다.
- 모르는 값은 `null`로 유지하고 0원으로 계산하지 않는다.
- 요청·응답과 계산 규칙은 `docs/api.md`를 따른다. 점수는 반올림(`0.5` 올림)한 시안이다.
- 근거에는 문서 식별자·출처·해당 위치를 남기고, 검색 실패를 정상 답변과 구분한다.
- 동 이름만으로 여러 매물이 남으면 `clarify`와 후보 ID를 반환한다.
- `management_overrides`는 한 번의 비교에만 적용되며 원본 매물이나 근거 문서를 바꾸지 않는다.
