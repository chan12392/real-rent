# 비용 계산·필터·정렬 · 분석

분석 담당자가 합의한 계산식과 판정 기준을 Python 일반 함수로 구현하는 경로다.
현재 구현된 함수는 없다. 기준은 `evaluation/criteria.md`, 합성 입력은
`data/demo/`, 자동 검사는 `backend/tests/domain/`에 둔다.

- 입력을 받아 결과를 반환한다. HTTP 요청, DB 접근, 파일 읽기와 LLM 호출은 함수 밖에서 처리한다.
- 금액은 원 단위 정수, 기간은 개월, 통근은 분이다. 미확인 값은 `None`으로 유지한다.
- 비용·필터·정렬을 AI 설명과 분리한다. 개발 3은 이 함수의 결과를 설명에 사용한다.
- 경계값, 미확인 값, 후보 없음, 동률의 기대값을 먼저 정하고 검사한다.
- 함수의 인자·반환값을 바꾸면 호출하는 개발 2·3과 테스트를 함께 수정한다.
