# 토끼 표정 에셋

`rabbit-expression-atlas.png`는 대화에서 사용자가 선택한 6가지 우사기 표정 시트를
입력 이미지로 사용해 built-in image_gen으로 배경·텍스트를 제거하고 정렬한 웹용 에셋이다.
새 SVG 디자인으로 대체하지 않는다. 원본 생성 식별자: exec-24d798b8-b5f9-4d7a-98a4-d08388bfb8bf.
변환 결과: exec-41269892-ae99-43e4-a0ee-d93490e126dc.

1536×1024 RGBA PNG, 3열×2행. 좌상단부터 기본/추천/쏘쏘/비추/판단 불가/검색 중.
각 셀은 512×512. Rabbit.tsx와 explore.css에서 같은 파일을 참조한다.
표정은 페이드 전환, 동작은 이미지 전체의 CSS 변환이다. 부위별 리깅이나 프레임 애니메이션은 아니다.

변환 프롬프트 요약: 기존 캐릭터 외형·색·포즈 유지, 배경·글자 제거, 투명 3×2 균등 그리드,
전체 귀·소품 포함, 같은 크기와 기준선, 새 디자인·라벨·테두리 없음.
