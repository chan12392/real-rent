# 이미지 생성용 빈칸 템플릿

**권리 있는 캐릭터만 쓰고, 이 폴더의 결과물은 커밋·공유하지 말 것.**
아래 `{캐릭터 설명}`만 직접 만든 캐릭터의 설명으로 채운다. 사용 도구의 이용 조건·권리와 생성 비용은 직접 확인한다.
각 문장은 해당 파일 한 장용이다. 완성한 기본 이미지를 참조로 함께 주고, 동일한 실루엣·비율·발 위치를 유지한다.
배경 투명도는 생성 후 확인하며 자세한 규격은 [POSES.md](POSES.md)를 따른다.

| 출력 파일 | 입력 문장 |
| --- | --- |
| `neutral.png` | {캐릭터 설명}. 편안하게 정면을 보는 기본 표정으로 전신을 중앙에 그려 줘. 투명 배경 1024×1024 PNG, 동일 카메라·조명·비율, 발은 같은 바닥선, 사방에 여백, 배경·그림자·문자 없음. |
| `excited.png` | {캐릭터 설명}. 기본 이미지와 같은 실루엣·크기·위치에서 눈과 입만 밝게 웃으며 반기는 표정으로 바꿔 줘. 정면 전신, 투명 배경 1024×1024 PNG, 배경·그림자·문자 없음. |
| `thinking.png` | {캐릭터 설명}. 기본 이미지와 같은 실루엣·크기·위치에서 눈썹을 살짝 모으고 궁금해하는 표정으로 바꿔 줘. 몸을 기울이지 않은 정면 전신, 투명 배경 1024×1024 PNG, 배경·그림자·문자 없음. |
| `worried.png` | {캐릭터 설명}. 기본 이미지와 같은 실루엣·크기·위치에서 상대에게 공감하며 부드럽게 걱정하는 표정으로 바꿔 줘. 정면 전신, 투명 배경 1024×1024 PNG, 배경·그림자·문자 없음. |
| `surprised.png` | {캐릭터 설명}. 기본 이미지와 같은 실루엣·크기·위치에서 눈을 조금 크게 뜨고 놀라는 표정으로 바꿔 줘. 점프하지 않는 정면 전신, 투명 배경 1024×1024 PNG, 배경·그림자·문자 없음. |
| `sorry.png` | {캐릭터 설명}. 기본 이미지와 같은 실루엣·크기·위치에서 미안함과 아쉬움을 담은 부드러운 표정으로 바꿔 줘. 과하게 숙이지 않는 정면 전신, 투명 배경 1024×1024 PNG, 배경·그림자·문자 없음. |
| `blink.png` | {캐릭터 설명}. 기본 이미지에서 눈만 자연스럽게 감아 줘. 눈 이외의 표정·자세·실루엣·크기·위치를 그대로 유지한 정면 전신, 투명 배경 1024×1024 PNG, 배경·그림자·문자 없음. |
