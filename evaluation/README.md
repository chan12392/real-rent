# 시연 데이터·계산·검증 · 분석

`criteria.md`에 계산식·필터·정렬 기준을 정리하고 개발 2·3과 입력·출력 형식을 합의한다.
분석 담당자가 `backend/app/domain/`에 함수, `backend/tests/domain/`에 자동 검사를 구현한다.
서버와 같은 Python 3.12 환경에서 `backend/README.md`의 검사 명령을 사용한다.
개발 3은 계산 결과를 받아 추천 이유를 작성한다.

시연 데이터는 `data/demo/`, 공유할 근거 문서와 출처는 `data/references/`에서 관리한다.
`cases.template.csv`를 복사·확장해 검증 사례 20개를 작성하고, 기대값은 수작업으로 먼저 계산한다.
현재 검증 사례와 평가 결과는 아직 작성하지 않았다. 템플릿의 빈 칸을 통과로 간주하지 않는다.

검증에는 일반 조건, 예산 경계, 기간 미달, 관리비 미확인, 후보 없음, 외부 조회 실패,
검색 근거 없음 등을 포함한다. 결과를 기록할 때 사용한 데이터와 Git 커밋도 남긴다.
자동 검사와 수작업 평가는 별개로 보고한다.
개발 1·2·3의 검증 결과를 이곳에 취합하되 담당자·실행일·환경·통과/실패·미검증을 구분한다.
