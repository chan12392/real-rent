# 계산·추천 기준 합의표

상태: **초안 / 미합의 / 미구현**. 분석 담당자가 아래 기준을 정리하고 개발 2·3과 합의한 뒤
`backend/app/domain/`에 비용 계산·필터·정렬 함수를 구현한다.

| 항목 | 합의할 내용 | 상태 |
| --- | --- | --- |
| 초기 필요 현금 | 보증금·선납·이사·중개 등 포함 항목과 계산식 | 미합의 |
| 월 지출 | 임대료·관리비·공과금·통근 비용 포함 여부 | 미합의 |
| 거주 기간 지출 | 보증금 반환 가정, 일회성 비용, 기간 처리 | 미합의 |
| 필수 조건 | 예산·최소 계약 기간·통근 등 배제 기준 | 미합의 |
| 추천 순서 | 비용과 선호 조건의 우선순위 및 동률 처리 | 미합의 |
| 미확인 값 | 추가 질문과 판단 불가 표시 기준 | 미합의 |
| 근거 | 문서 출처·기준 시점·해당 위치 표시 방법 | 미합의 |

금액은 원 단위 정수로 비교한다. 불명확한 수수료·혜택·자격을 확정값으로 계산하지 않는다.
외부 기준을 반영할 때는 공식 출처와 확인 날짜를 함께 기록한다.
