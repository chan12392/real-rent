# 공유 입력 예시

`listings.json`은 팀 연결 규약을 논의하기 위해 직접 만든 **합성 데이터**다.
실제 매물, 주소, 시세 또는 부동산 추천으로 사용하지 않는다. 현재 서버가 자동 적재하지 않는다.

금액은 원, 기간은 개월, 통근은 분이다. `null`은 미확인 값으로 0과 다르다.
형식 변경 시 `docs/api.md`와 화면·서버 담당자에게 함께 공유한다.

`listings.csv`(매물 12건)와 `commute_fixture.csv`(출근·퇴근 경로)는 서버가 실제로 읽는 시연 데이터다.
역시 **가정값**이며 실거래 API와 교통 API를 조회하지 않았다. `L03` 관리비 미확인, `L12` 경로 실패처럼
경계 사례를 일부러 포함했다. 형식을 바꾸면 `backend/tests`를 함께 갱신한다.
