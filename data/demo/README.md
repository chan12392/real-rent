# 공유 입력 예시

분석 담당자가 시연 데이터를 준비하고 개발 1·2·3과 입력·출력 예시를 맞춘다.

`listings.json`은 개발용 API가 읽는 **합성 데이터**다.
실제 매물, 주소, 시세 또는 교통 조회 결과로 사용하지 않는다.
`schema_version: 2`는 회사 2곳, 가상 매물 4개, 회사·매물별 출근·퇴근 경로를 담는다.
서버는 요청마다 파일과 식별자·경로 연결을 검사한다. 시연 중 수정 후 재실행할 필요가 없다.

금액은 원, 통근은 도보 포함 분이다. `null`은 미확인 값으로 0과 다르다.
C의 관리비와 강남 방향 경로는 미확인 사례다. B·D는 회사 변경 시 통근 상한 미달 사례가 된다.
기본 입력은 2026-11-01 입주·서울역·월 20일·상한 800,000원이며 기대 순서는 D → A → B다.
이 4개는 개발 확인용이다. 전체 요구사항의 실제 검증 데이터가 준비되었다는 의미는 아니다.
형식 변경 시 `docs/api.md`, 서버 모델·테스트와 화면 응답 검사를 함께 수정한다.
