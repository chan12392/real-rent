# 공유 근거 문서 · 분석

RAG와 추천 이유에 사용할 공유 가능한 근거 문서를 관리한다.
`explore.json`은 기존 `data/demo/explore.json`의 합성 매물 12건에서 관리비 포함 항목과
자료 한계를 옮긴 개발용 문서다. 외부 출처로 검증한 매물 자료나 실제 계약 문서가 아니다.
문서의 `listing_id`로 검색 범위를 제한하고 `title`·`quote`·`as_of`를 화면에 표시한다.
실제 분석 자료가 준비되면 같은 ID와 형식을 유지해 교체한다.
문서마다 식별자, 제목, 출처 URL, 확인 날짜, 인용할 페이지·절, 시연용 여부를 함께 남긴다.
개발 3은 이 식별자와 위치를 검색 결과·추천 이유에 연결한다.

공유 권한이 있는 자료만 커밋한다. 원본 개인정보·계약서는 `data/raw/`에 두고 Git에 넣지 않는다.
벡터 인덱스는 `data/indexes/`, 조회 캐시는 `data/cache/`의 로컬 생성물로 관리한다.
